## 9. Gotchas this run hit

- **Test variables.** `smoke_test.gd`'s `_run()` is one long function. Declaring a local that
  is already in scope (an earlier one in the function, or an outer one from a nested block) is
  a parse error ("already a variable named …"), and the headless run then hangs. Prefix new
  locals (`hl_`, `gw_`, …).
- **Type inference.** `:=` can't infer from a call on the untyped `game` node in tests
  (`var x: int = game.path.mid_arena()`), nor from Dictionary or Variant access.
- **Placing the ship in a probe.** Putting it past sealed bulkheads makes
  `PlayerShip._door_collide` (via `world.door_blocking`) shove it back to the first one. Open the
  earlier doors first, as a resume does.
- **Smoke-test isolation.** Later sections can inherit a kill streak (`GameState.combo`) and
  enemy shots from earlier ones. `ShotManager.clear_all()` now clears `eshot_cache`. Reset what
  a check depends on.
- **HUD messages.** Several in one frame overwrite each other until v4d's log. Order the emits
  (`_kill` emits `miniboss_killed` before `enemy_killed`, so the bulkhead's checkpoint knows).
- **Netlify** previews take a few minutes; watch the status with Monitor. Rendered perf on
  llvmpipe has rare one-off stalls; rerun before calling anything a regression.
