# CLAUDE.md — VOID RUNNER (Godot repo)

This repository is the Godot rebuild of VOID RUNNER. **The full project documentation lives one
directory up**, outside this repo, in the parent `RadixRemix/` folder:

- `../CLAUDE.md` — session orientation, project history, constraints. **Read it first.**
- `../PLAN.md` — the phased build sequence (A–H) with verification gates. Work top to bottom.
- `../PROJECT.md` — design reference: tuning tables (§5), authenticity research (§11–§12), legal
  guardrails (§13).
- `../reference/void-runner-v2.2.html` — the frozen web prototype; canonical feature spec.
- `../reference/NOTES.md` — study-pass design brief (the 5 "feel" pillars = Phase G gate criteria).
- `../reference/originals/` — 1995 shareware research files. **Never copy anything from there into
  this repo.** `reference/` is gitignored here as belt-and-suspenders.

## Hard rules for this repo

1. Everything shipped is procedurally generated by code in this repo. No imported assets, ever.
2. Never name the specific commercial '95 DOS game this project draws inspiration from (or its
   original studio/publisher) in code, text, or docs here — refer to the genre generically
   ("'95 DOS games," "mid-90s DOS tunnel-shooters").
3. No GPL code. MIT only.
4. Child-friendly tone in all game text.

## Pipeline facts

- `netlify.toml` → `build.sh` exports the "Web" preset on Netlify's build image (pinned
  `GODOT_VERSION`, independent of the local editor). Publish dir: `dist/`.
- Web export has `thread_support=false` so it runs on iPad Safari; keep it that way unless
  desktop-only performance forces a revisit.
- Rendering profile (do not break): 320×200 viewport stretch `keep`, GL Compatibility,
  nearest-neighbor default filtering, no AA. Every asset is designed for this, per `../PLAN.md`
  Phase B.
